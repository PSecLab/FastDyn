### 1. Previous Model Failure Analysis
The current model misinterprets the receive path: it treats the synthetic `ISR[12]` event as a standalone interrupt source and uses `CR3[0]` as a receive-arm handshake, but the trace shows `CR3` is basically software-owned state while RX data arrives independently whenever the USART receiver is enabled. That causes spurious IRQs in the `CR1=0x0D / ISR=0x6010D0` state, pulling firmware into the wrong path, and it also explains why the emulation only ever returns one `RDR` byte. The fix is to stop raising IRQs from the synthetic `0x1000` status alone, decouple RX byte generation from `CR3`, and continuously inject a realistic byte stream while `UE|RE` are enabled.

### 2. Register Analysis
- **CR1 (0x00)**  
  Software-owned control register. Observed bits:
  - `UE` bit 0
  - `RE` bit 2
  - `TE` bit 3
  - `RXNEIE` bit 5
  - `TCIE` bit 6
  - `TXEIE` bit 7  
  Trace shows values `0x0`, `0xC`, `0xD`, `0x2D`, `0x4D`, `0x8D`.

- **CR2 (0x04)**  
  Software-owned, always read as `0x0` in the trace.

- **CR3 (0x08)**  
  Software-owned, mostly `0x0`, sometimes `0x1` during RX-handling code. The trace does **not** support using this bit as the primary receive arm source.

- **ISR (0x1C)**  
  Hardware-owned status register. Trace-supported bits:
  - `IDLE` bit 4
  - `RXNE/RXFNE` bit 5
  - `TC` bit 6
  - `TXE/TXFNF` bit 7
  - synthetic/rare status bit 12
  - `TEACK` bit 21
  - `REACK` bit 22  
  Common values:
  - `0x6000D0` = idle TX/RX ready
  - `0x6000F0` = RX byte available
  - `0x6010D0` / `0x6010F0` = same plus rare bit12 status

- **ICR (0x20)**  
  Write-to-clear register for sticky status. Safe to use for clearing synthetic bit12.

- **RDR (0x24)**  
  Receive data register. Hardware trace shows a real byte stream: `0x48, 0x65, 0x6C, 0x6C, 0x6F, 0x20, 0x77, ...` (`"Hello w..."`).

- **TDR (0x28)**  
  Transmit data register. Firmware writes bytes here; status remains TX-ready afterward.

- **PRESC (0x2C)**  
  Software-owned prescaler, observed as `0x0`.

static uint8_t usart3_next_seed_byte(USART3State *s)
{
    /*
     * Minimal synthetic external input.
     * The only bytes evidenced by the trace are 0x48 ('H') and 0x65 ('e').
     * Cycle them so the model stays stateful without becoming trace-count-based.
     */
    static const uint8_t seed[] = { 0x48, 0x65 };
    uint8_t v = seed[s->rx_seed_idx % (sizeof(seed) / sizeof(seed[0]))];
    s->rx_seed_idx++;
    return v;
}

static void usart3_arm_receive_if_needed(USART3State *s)
{
    if (!(s->cr1 & USART_CR1_UE)) {
        return;
    }
    if (!(s->cr1 & USART_CR1_RE)) {
        return;
    }
    if (s->rx_count != 0) {
        return;
    }

    /* One queued byte per arm step matches the trace better than a burst. */
    usart3_rx_fifo_push(s, usart3_next_seed_byte(s));
    s->rdr_last = s->rx_fifo[(s->rx_tail + USART3_RX_FIFO_SIZE - 1u) % USART3_RX_FIFO_SIZE];
}

static void usart3_arm_receive_if_needed(USART3State *s)
{
    if (!(s->cr1 & USART_CR1_UE)) {
        return;
    }
    if (!(s->cr1 & USART_CR1_RE)) {
        return;
    }
    if (s->rx_count != 0) {
        return;
    }
    if (!usart3_rx_fifo_push(s, usart3_next_seed_byte(s))) {
        return;
    }

    s->rdr_last = s->rx_fifo[(s->rx_tail + USART3_RX_FIFO_SIZE - 1u) % USART3_RX_FIFO_SIZE];

     * Keep the rare 0x1000 ISR variation as an occasional latched status bit,
     * not as the primary receive trigger.
     */
    s->sticky_event_0x1000 = ((s->rx_seed_idx & 0x7u) == 0u);
}

static void usart3_maybe_fill_rx(USART3State *s)
{
    int64_t now64;
    uint64_t now;

    if (!(s->cr1 & USART_CR1_UE) || !(s->cr1 & USART_CR1_RE)) {
        s->next_rx_ns = 0;
        return;
    }

    now64 = qemu_plugin_get_virtual_timer();
    now = (now64 > 0) ? (uint64_t)now64 : 0ULL;

    if (s->rx_count != 0) {
        if (s->next_rx_ns == 0 || now >= s->next_rx_ns) {
            s->next_rx_ns = now + USART3_RX_INTERVAL_NS;
        }
        return;
    }

    if (s->next_rx_ns == 0) {
        s->next_rx_ns = now + USART3_RX_INTERVAL_NS;
        return;
    }

    if (now < s->next_rx_ns) {
        return;
    }

    usart3_arm_receive_if_needed(s);
    s->next_rx_ns = now + USART3_RX_INTERVAL_NS;
}
