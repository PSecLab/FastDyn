### 1. High-Level Summary
This trace shows STM32H753 ADC1 being brought out of low-power state, regulator-enabled, calibrated, configured for a single regular channel sequence, and then started in a DMA-driven continuous sampling mode. ADC2 is only lightly probed, and ADC12 common control is touched through CCR. The repeated interrupt storm is much more consistent with DMA1 Stream1 servicing ADC1->DR transfers than with direct ADC IRQ delivery, so the ADC model should mainly provide sane register state, generate conversion samples, update ADC status flags, and issue DMA requests carrying ADC sample data.

### 2. Register Analysis
- **ADC1/ADC2 @ offset 0x08 — CR**
  - Used for power-state transitions, regulator enable, calibration sequencing, ADC enable, and start conversion.
  - Observed values strongly suggest:
    - `0x20000000` / `0x10000000` used for deep-power-down / regulator sequencing
    - `0x80000000` involved in calibration launch
    - bit0 used as enable
    - bit2 used as regular conversion start
- **ADC1 @ offset 0x00 — ISR**
  - Written with `0x7ff` to clear flags.
  - Later reads show `0x00001001`, `0x0000100b`, `0x0000100f`, consistent with a hardware-owned ready/status register.
  - Model should treat writes as W1C.
- **ADC1 @ offset 0x04 — IER**
  - Initially zero, later written with `0x10`; simple RW interrupt-enable behavior is sufficient.
- **ADC1 @ offset 0x0C — CFGR**
  - Written first with `0x00200000`, later `0x80003000`, then `0x80003003`.
  - Likely includes DMA enable / circular / overrun-related settings; trace only requires RW storage.
- **ADC1 @ offset 0x10 — CFGR2**
  - Read/written as zero; simple RW.
- **ADC1 @ offsets 0x14 / 0x18 — SMPR1 / SMPR2**
  - SMPR1 later set to `0x00000400`; SMPR2 stays zero.
- **ADC1 @ offset 0x1C — PCSEL**
  - Later written `0x00000008`, consistent with selecting regular channel 3 preselection.
- **ADC1 @ offset 0x30 — SQR1**
  - Later written `0x000000c0`, consistent with a one-channel regular sequence selecting channel 3.
- **ADC1 @ offset 0x40 — DR**
  - Not directly read in this trace, but DMA PAR is programmed to `0x40022040`, so this must be ADC1 data register from the firmware’s point of view.
- **ADC12 Common @ offset 0x08 — CCR**
  - Read as zero, later written `0x00040000`, then read back; simple RW storage is enough.
- **ADC1 miscellaneous offsets**
  - `0x20, 0x24, 0x60, 0x64, 0x68, 0x6C, 0xA0, 0xA4, 0xB0..0xBC, 0xC0, 0xC4`
  - Accessed only as zeroed configuration/state placeholders; implement as plain RW registers.
- **DMA interaction**
  - DMA register programming clearly points to **DMA1 Stream1** using peripheral address `0x40022040` (ADC1 DR).
  - ADC model should therefore emit conversion data through `api_dma_request_data(1, ...)`.

### 3. C Device Model Source Code
```c
// Device Model for ADC

#include <device.h>
#include <boardrunner/vio.h>
#include <stdint.h>
#include <stdbool.h>
#include <string.h>
#include <stdio.h>

#define ADC1_BASE        0x40022000ULL
#define ADC2_BASE        0x40022100ULL
#define ADC12_COMMON_BASE 0x40022300ULL

/* Inferred bit usage from trace / STM32H7 ADC semantics */
#define ADC_ISR_ADRDY    (1u << 0)
#define ADC_ISR_EOSMP    (1u << 1)
#define ADC_ISR_EOC      (1u << 2)
#define ADC_ISR_EOS      (1u << 3)
#define ADC_ISR_LDORDY   (1u << 12)   /* inferred from recurring 0x1000 */

#define ADC_CR_ADEN      (1u << 0)
#define ADC_CR_ADSTART   (1u << 2)
#define ADC_CR_ADVREGEN  (1u << 28)
#define ADC_CR_DEEPPWD   (1u << 29)
#define ADC_CR_ADCAL     (1u << 31)

#define ADC_FIFO_PATH    "/tmp/adc_samples"
#define ADC_DMA_STREAM   1            /* inferred from DMA1 Stream1 programming */
#define ADC_SAMPLE_PERIOD_NS 10000ULL /* arbitrary but responsive */

typedef struct {
    uint32_t isr;
    uint32_t ier;
    uint32_t cr;
    uint32_t cfgr;
    uint32_t cfgr2;
    uint32_t smpr1;
    uint32_t smpr2;
    uint32_t reg_20;
    uint32_t reg_24;
    uint32_t pcsel;
    uint32_t sqr1;
    uint32_t dr;
    uint32_t reg_60;
    uint32_t reg_64;
    uint32_t reg_68;
    uint32_t reg_6c;
    uint32_t reg_a0;
    uint32_t reg_a4;
    uint32_t reg_b0;
    uint32_t reg_b4;
    uint32_t reg_b8;
    uint32_t reg_bc;
    uint32_t reg_c0;
    uint32_t reg_c4;
    bool running;
} ADCUnit;

typedef struct {
    ADCUnit adc1;
    ADCUnit adc2;
    uint32_t ccr;

    int fifo_fd;
    uint8_t fifo_tmp[2];
    int fifo_tmp_len;
    uint16_t default_sample;

    uint64_t sample_timer;
} ADCState;

static ADCState g_adc;

/* ---------- Helpers ---------- */

static void adc_dbg(const char *msg) {
    char buf[128];
    snprintf(buf, sizeof(buf), "ADC: %s", msg);
    dev_debug(buf);
}

static uint16_t adc_pull_sample(ADCState *s) {
    uint8_t b;

    while (s->fifo_tmp_len < 2) {
        if (api_fifo_read_nonblock(s->fifo_fd, &b) != 1) {
            break;
        }
        s->fifo_tmp[s->fifo_tmp_len++] = b;
    }

    if (s->fifo_tmp_len == 2) {
        uint16_t v = (uint16_t)s->fifo_tmp[0] | ((uint16_t)s->fifo_tmp[1] << 8);
        s->fifo_tmp_len = 0;
        return v;
    }

    return s->default_sample;
}

static void adc_complete_regular_conversion(ADCState *s) {
    uint16_t sample;
    uint8_t payload[2];

    if (!(s->adc1.cr & ADC_CR_ADEN) || !s->adc1.running) {
        return;
    }

    sample = adc_pull_sample(s);
    s->adc1.dr = sample;

    /* Ready + regular conversion flags */
    s->adc1.isr |= (ADC_ISR_LDORDY | ADC_ISR_ADRDY | ADC_ISR_EOSMP |
                    ADC_ISR_EOC | ADC_ISR_EOS);

    payload[0] = (uint8_t)(sample & 0xff);
    payload[1] = (uint8_t)((sample >> 8) & 0xff);

    /*
     * DMA1 Stream1 is configured by firmware with PAR = ADC1_DR (0x40022040),
     * so emit the conversion result through the payload DMA API.
     */
    if (api_dma_request_data(ADC_DMA_STREAM, payload, 2) == 0) {
        /*
         * On successful handoff, make ISR look a little closer to the trace:
         * EOC may be transient, while EOS/EOSMP/ADRDY/LDORDY stay visible.
         */
        s->adc1.isr &= ~ADC_ISR_EOC;
    }
}

static void adc_timer_cb(void *opaque) {
    ADCState *s = (ADCState *)opaque;
    adc_complete_regular_conversion(s);
}

static uint64_t adc_unit_read(ADCUnit *u, hwaddr offset) {
    switch (offset) {
    case 0x00: return u->isr;
    case 0x04: return u->ier;
    case 0x08: return u->cr;
    case 0x0C: return u->cfgr;
    case 0x10: return u->cfgr2;
    case 0x14: return u->smpr1;
    case 0x18: return u->smpr2;
    case 0x1C: return u->pcsel;
    case 0x20: return u->reg_20;
    case 0x24: return u->reg_24;
    case 0x30: return u->sqr1;
    case 0x40: return u->dr;
    case 0x60: return u->reg_60;
    case 0x64: return u->reg_64;
    case 0x68: return u->reg_68;
    case 0x6C: return u->reg_6c;
    case 0xA0: return u->reg_a0;
    case 0xA4: return u->reg_a4;
    case 0xB0: return u->reg_b0;
    case 0xB4: return u->reg_b4;
    case 0xB8: return u->reg_b8;
    case 0xBC: return u->reg_bc;
    case 0xC0: return u->reg_c0;
    case 0xC4: return u->reg_c4;
    default:
        return 0;
    }
}

static void adc_unit_write(ADCState *s, ADCUnit *u, bool is_adc1, hwaddr offset, uint32_t value) {
    switch (offset) {
    case 0x00:
        /* ISR is W1C for the flags we expose */
        u->isr &= ~value;
        break;

    case 0x04:
        u->ier = value;
        break;

    case 0x08:
        /*
         * CR handling kept deliberately simple and trace-driven:
         * - raw power-state writes echo back
         * - calibration launch completes immediately
         * - ADEN sets ADRDY-like state
         * - ADSTART starts continuous conversions
         */
        if (value & ADC_CR_ADCAL) {
            /*
             * Trace shows write 0x90010200, then readback 0x1fc10200.
             * Model that directly.
             */
            u->cr = 0x1FC10200u;
            u->isr |= ADC_ISR_LDORDY;
            u->running = false;
        } else {
            u->cr = value;

            if (value == 0) {
                u->running = false;
                u->isr = 0;
            } else {
                if (value & ADC_CR_ADVREGEN) {
                    u->isr |= ADC_ISR_LDORDY;
                }

                if (value & ADC_CR_ADEN) {
                    /* trace-visible ready state: 0x00001001 */
                    u->isr |= (ADC_ISR_LDORDY | ADC_ISR_ADRDY);
                }

                if (value & ADC_CR_ADSTART) {
                    u->running = true;
                    if (is_adc1) {
                        /* immediate first sample so firmware does not stall */
                        adc_complete_regular_conversion(s);
                    }
                } else if (!(value & ADC_CR_ADEN)) {
                    u->running = false;
                }
            }
        }

        /*
         * ADC2 is only lightly probed, but the trace later sees ADC2.CR at
         * 0x20000000 after ADC1 power-state manipulation. Seed that behavior.
         */
        if (is_adc1 && value == 0x20000000u && s->adc2.cr == 0) {
            s->adc2.cr = 0x20000000u;
        }
        break;

    case 0x0C: u->cfgr = value; break;
    case 0x10: u->cfgr2 = value; break;
    case 0x14: u->smpr1 = value; break;
    case 0x18: u->smpr2 = value; break;
    case 0x1C: u->pcsel = value; break;
    case 0x20: u->reg_20 = value; break;
    case 0x24: u->reg_24 = value; break;
    case 0x30: u->sqr1 = value; break;
    case 0x60: u->reg_60 = value; break;
    case 0x64: u->reg_64 = value; break;
    case 0x68: u->reg_68 = value; break;
    case 0x6C: u->reg_6c = value; break;
    case 0xA0: u->reg_a0 = value; break;
    case 0xA4: u->reg_a4 = value; break;
    case 0xB0: u->reg_b0 = value; break;
    case 0xB4: u->reg_b4 = value; break;
    case 0xB8: u->reg_b8 = value; break;
    case 0xBC: u->reg_bc = value; break;
    case 0xC0: u->reg_c0 = value; break;
    case 0xC4: u->reg_c4 = value; break;
    default:
        break;
    }
}

/* ---------- MMIO callbacks ---------- */

// This function will emulate all device reads
uint64_t adc_read(void *opaque, hwaddr addr, unsigned size) {
    ADCState *s = (ADCState *)opaque;

    if (size != 4) {
        return 0;
    }

    if (addr >= ADC1_BASE && addr < (ADC1_BASE + 0x100)) {
        hwaddr offset = addr - ADC1_BASE;

        /*
         * Synchronous check: if firmware polls DR while conversion is active,
         * ensure at least one sample exists.
         */
        if (offset == 0x40 && s->adc1.running && s->adc1.dr == 0) {
            adc_complete_regular_conversion(s);
        }

        return adc_unit_read(&s->adc1, offset);
    }

    if (addr >= ADC2_BASE && addr < (ADC2_BASE + 0x100)) {
        hwaddr offset = addr - ADC2_BASE;
        return adc_unit_read(&s->adc2, offset);
    }

    if (addr >= ADC12_COMMON_BASE && addr < (ADC12_COMMON_BASE + 0x20)) {
        hwaddr offset = addr - ADC12_COMMON_BASE;
        switch (offset) {
        case 0x08:
            return s->ccr;
        default:
            return 0;
        }
    }

    return 0;
}

// This function will emulate all device writes
void adc_write(void *opaque, hwaddr addr, uint64_t value, unsigned size) {
    ADCState *s = (ADCState *)opaque;
    uint32_t v = (uint32_t)value;

    if (size != 4) {
        return;
    }

    if (addr >= ADC1_BASE && addr < (ADC1_BASE + 0x100)) {
        hwaddr offset = addr - ADC1_BASE;
        adc_unit_write(s, &s->adc1, true, offset, v);
        return;
    }

    if (addr >= ADC2_BASE && addr < (ADC2_BASE + 0x100)) {
        hwaddr offset = addr - ADC2_BASE;
        adc_unit_write(s, &s->adc2, false, offset, v);
        return;
    }

    if (addr >= ADC12_COMMON_BASE && addr < (ADC12_COMMON_BASE + 0x20)) {
        hwaddr offset = addr - ADC12_COMMON_BASE;
        switch (offset) {
        case 0x08:
            s->ccr = v;
            break;
        default:
            break;
        }
    }
}

// MUST return pointer to state — framework passes it as opaque to _read/_write
void* adc_init(ConfigSection* model_info) {
    (void)model_info;

    memset(&g_adc, 0, sizeof(g_adc));

    g_adc.default_sample = 0x0800; /* sensible midpoint default */
    g_adc.fifo_fd = api_fifo_open(ADC_FIFO_PATH);
    g_adc.fifo_tmp_len = 0;

    /*
     * Free-running sample source. The callback only emits data while ADC1 is
     * actually running.
     */
    g_adc.sample_timer = qemu_plugin_timer_new_period_ns(adc_timer_cb, &g_adc,
                                                         ADC_SAMPLE_PERIOD_NS);

    adc_dbg("initialized");
    return &g_adc;
}
```

### 4. Host-Side Setup
The model auto-creates a FIFO at:

```text
/tmp/adc_samples
```

To feed 16-bit little-endian ADC samples into ADC1 channel conversions from the host, run after the VM/model starts:

```bash
python3 - <<'PY'
import os, struct, time
fd = os.open("/tmp/adc_samples", os.O_WRONLY)
while True:
    os.write(fd, struct.pack("<H", 0x0800))  # example sample
    time.sleep(0.001)
PY
```

If you do not provide host samples, the model defaults to `0x0800`.
