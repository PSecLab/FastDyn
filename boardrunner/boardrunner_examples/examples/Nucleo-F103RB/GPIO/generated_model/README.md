We have two options to choose for the models generated by LLM for this case.
Either you can use socat to run the model or fifo.

Also, you can generate these flavors by just using one of two options ('REQ', 'NOT-REQ')
```bash
fastdyn generate -hw hardware_log/io.log -b STM32F103xx -p GPIOA -p GPIOC -mname "GPIO" -observability "REQ"
```

# Option 1: SOCAT
Run this command in a separate terminal:
```bash
socat -d -d PTY,link=/tmp/usart1_pty,raw,echo=0 STDIO
```

# Option 2: FIFO
```bash
cat /tmp/gpioa_out
# (optional) also:
cat /tmp/gpioc_out

#to turn on and off the leds
printf '\x00' > /tmp/gpioc_in
printf '\x01' > /tmp/gpioc_in
```

# Option 3: For fuzzing!
No external command required.
